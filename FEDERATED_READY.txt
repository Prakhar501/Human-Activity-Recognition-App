🧠 FEDERATED AVERAGING (FedAvg) ALGORITHM
═══════════════════════════════════════════════════════════════════════════════

Implemented Workflow:

Round 1 → R:
  1. Server broadcasts global model weights to all K clients
  2. Each client:
     • Downloads global weights
     • Trains locally for E epochs on its data partition
     • Computes updated weights
  3. Server collects all updated weights
  4. Server performs FedAvg aggregation:
     
     w_global = Σ(n_k / n_total) × w_k
     
     where:
       n_k = samples on client k
       n_total = total samples across all clients
  
  5. Server updates global model with aggregated weights
  6. Global model evaluated on shared test set
  7. Log metrics and proceed to next round

Final: Compare federated accuracy with centralized baseline

🔄 DATA FLOW EXAMPLE (5 Clients, 1 Round)
═══════════════════════════════════════════════════════════════════════════════

Combined Dataset (10,000 samples, shuffled)
    │
    ├─→ Client 0: 2,000 samples
    ├─→ Client 1: 2,000 samples
    ├─→ Client 2: 2,000 samples
    ├─→ Client 3: 2,000 samples
    └─→ Client 4: 2,000 samples
    
Test Set: 5,000 samples (shared, not used in training)

ROUND 1:
────────
Server broadcasts: w_global_0

Client 0 trains:  20 batches (2000÷32×5 epochs) → updates w_0
Client 1 trains:  20 batches                    → updates w_1
Client 2 trains:  20 batches                    → updates w_2
Client 3 trains:  20 batches                    → updates w_3
Client 4 trains:  20 batches                    → updates w_4

Server Aggregates:
  w_global_1 = 0.2×w_0 + 0.2×w_1 + 0.2×w_2 + 0.2×w_3 + 0.2×w_4

Server Evaluates:
  accuracy_1 = evaluate(w_global_1, test_set)

Output:
  Round 1: Accuracy 71.56% (improving from random initialization)

🔧 TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Problem: "No such file or directory"
→ Solution: Check dataset paths in CONFIG. Ensure dataset/ folder exists.

Problem: Out of memory
→ Solution: Reduce batch_size (32→16) or num_clients (5→2)

Problem: Accuracy is 50% (random)
→ Solution: Check data loads correctly. Verify label mapping.

Problem: Very slow training
→ Solution: Reduce num_global_rounds (10→5) or local_epochs (5→2)

Problem: Federated much lower than centralized
→ Solution: Increase local_epochs (5→10) or num_global_rounds (10→20)

Problem: Import errors
→ Solution: pip install tensorflow pandas scikit-learn matplotlib
